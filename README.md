# Satzbau · 德语造句练习

一个基于 AI 的德语「中译德」造句练习应用。根据难度等级或你上传的词表生成中文句子，你用键盘打出对应的德语句子，AI 逐词批改并给出参考译文。

> **在线版（GitHub Pages）**：<https://vodkacranberry.github.io/satzbau/> — 手机/任意设备打开即用，无需安装。练习记录通过 LeanCloud 云同步互通。
>
> **macOS 桌面版**：`Satzbau-1.2.0-arm64.dmg`（本文件夹内，也可从 GitHub Releases 下载）——Electron 原生应用，带独立文件存储（`~/Library/Application Support/Satzbau/`）与前后端架构，功能与本网页版完全一致。双击 DMG 拖入 Applications 即可安装。

## 核心功能

- **主页即导航**：打开后是一个清爽的启动页，只显示各功能的入口卡片（开始练习 / 历史记录 / 学习统计 / 错题本 / 生词本 / 句子收藏夹 / 设置），每个功能独立成页，不互相拥挤
- **查词典（右上角）**：支持「德 → 中」与「中 → 德」双向搜索，模糊匹配（前缀 / 包含 / 近拼写纠错）；输入动词变位（如 `gegangen`、`ging`）自动识别并显示原型 `gehen`；输入时可点击 ä ö ü ß Ä Ö Ü 特殊字符快捷输入；离线内置 1000+ 常用词词典，查不到时自动调用 AI 查询，结果可一键加入生词本
- **词典详情页**：点击搜索结果即可展开详情——单词多义项、词性标注、名词复数、动词强/不规则变位表、构词与用法详细解释，以及带中文翻译的实用例句，全部支持朗读与收藏
- **按难度出题**：A1 / A2 / B1 / B2 / C1 / C2 六档，AI 严格按等级语法范围出题
- **按词表出题**：导入 `.txt` / `.csv` 词表（或直接粘贴），AI 出的题会尽量使用这些词
- **出题前选择语法要点**：内置 71 个德语语法知识点（祈使句、各种从句、连词、情态动词、被动语态、虚拟式、介词搭配等 7 大类），勾选后 AI 围绕所选要点出题；还可填写「额外要求」框进行更细化的练习指令。语法点面板默认收起，点「显示语法点」展开，再点一次隐藏
- **中文题面 → 德语作答**：附语法点说明、关键词语与提示；语法点说明默认隐藏，点「显示语法点」展开，再点一次隐藏；提示默认隐藏，点「显示提示」逐级展开（含逐词首字母骨架），再点可全部隐藏，按钮不会消失
- **AI 逐词批改（语法点导向）**：评分围绕你勾选的语法点验证句子是否命中，语法点之外鼓励自由发挥——即使结构与参考答案不同，只要意思正确且符合语法点即判定有效；输出：逐词批改、错误词 → 正确词对照、逐条中文解释、语法点逐项命中 ✓/✗、「改进你的句子」（保留你的思路只修正错误与润色）、多种不同结构的更优造句方案（附结构说明）、优点与学习建议
- **德语特殊字符快捷输入**：ä ö ü ß Ä Ö Ü 一键插入答题框
- **生词本**：查词、批改错误中的「＋ 生词」、手动添加三种方式积累生词，支持词性标注、筛选、朗读、导出 CSV，自动去重
- **句子收藏夹**：批改结果里的「参考译文 / 修正句」或手动输入一键收藏好句子，支持筛选、朗读、复制、导出
- **历史记录**：全部记录保存在浏览器本地，支持搜索、按状态/等级筛选、展开详情、再练一遍、删除、收藏
- **错题本**：自动收集低于 60 分的错题，从主页入口进入（自动按「错误」筛选）
- **学习统计**：累计练习、平均分、正确率、连续天数、每日进度条、各等级掌握度、近 14 天趋势、错误类型分布
- **发音朗读**：句子与单词一键朗读（含 0.6× 慢速跟读）；网页版用浏览器原生 TTS，桌面版调用 macOS 原生 `say` 德语语音（音质更佳），可在设置里选语音和语速
- **数据管理**：导出 / 导入 JSON 备份、导出 CSV，清空数据
- **数据存储（桌面版）**：JSON 文件原子写入 + 最多 3 份滚动备份，主文件损坏时自动从最近备份恢复；设置页可查看数据文件路径、备份数量，并一键在访达中打开
- **其他**：深浅色主题切换（跟随系统）、Ctrl/⌘+Enter 提交、N 换题、H 提示

## 隐私说明

- 题目与作答会发送至 DeepSeek API 用于生成与批改
- 全部练习记录仅保存在你的浏览器 localStorage 中，不上传任何服务器
